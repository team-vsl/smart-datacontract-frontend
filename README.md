## How to set up?

Instructions for setting things up:

### Setup environment file

1. In the project directory, create a `.env` file.
2. Copy all contents from `.env.example` to `.env`.
3. Fill in the missing information.

Or run this command to do it quickly:

```bash
cat .env.example > .env
```

### Project

1. First, you need to install all the required packages.

```bash
npm install

# Or
pnpm install
```

2. Start the application

```bash
npm run dev

# Or
pnpm run dev
```

3. You can enter the application via http://localhost:5173 and make sure you have a User Pool in Cognito.
